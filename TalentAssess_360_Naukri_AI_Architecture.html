📚 Technical Feasibility & Official Reference Resources

🏢 1. Naukri Integration Methods

How our application connects with Naukri effectively:

  • Naukri Resdex Enterprise API: Official developer integration provided by Info Edge (Naukri.com) for enterprise ATS systems to search, view, and fetch candidate CVs directly into software.
  • Naukri Resume Forwarding Webhook / Mail Parser: When applicants apply to Naukri postings, their profiles are routed through an automated ingestion email hook that extracts data straight into Django.
  • Playwright/Selenium Authenticated Agent: Headless authenticated worker for enterprise recruiter accounts with session management and proxy rotation.
Resdex REST API JSON / XML Feeds ATS Webhooks

🤖 2. Gemini AI Semantic Matcher

How the AI accurately determines suitable profiles:

  • Beyond Keyword Matching: Traditional ATS only counts words. Gemini AI understands contextual synonyms (e.g. knowing that FastAPI or Flask relates to Python backend experience).
  • Structured Output Schema: Gemini outputs strict JSON containing fitment percentage, verified projects, and red flags.
  • High Speed & Low Cost: Gemini 1.5 Flash / Flash-Lite processes full multi-page resumes in sub-second latency with negligible cost.
Google Gemini API PyPDF2 / pdfplumber JSON Structured Outputs

🗄️ 3. Database & Django Pipeline

Seamlessly fits our existing MySQL database:

  • Auto-Creation in `candidates`: Sourced candidates are created with `action_status = 'AI_Qualified'` without manual recruiter entry.
  • Integration with `candidate_invites`: Automatically pairs candidate with the newly updated WYSIWYG Call Letter template.
  • Zero Human Intervention: Reduces recruitment turnaround time from 5 days to 15 minutes!
Django 4.x MySQL 8.0 Celery / Redis / Background Tasks
